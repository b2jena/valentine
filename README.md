# Valentine's Day Website for Aradhana ❤️

A unique, game-based interactive Valentine's experience with Stranger Things aesthetic.

## Features
✨ **Elegant Optima Font** - Beautiful, readable typography with system fallbacks
✨ **Attractive Shadows** - Multi-layer glow effects and depth shadows
✨ **Stranger Things Theme** - Iconic red glow, retro CRT effects
✨ **Interactive Story Game** - Multiple choice paths and branching narrative
✨ **Minimalist Design** - Clean, focused, distraction-free
✨ **Fully Responsive** - Perfect on phones, tablets, and desktops (360px to 1920px+)
✨ **Smooth Animations** - Typewriter effects, glowing text, button transitions
✨ **Touch-Optimized** - Large touch targets for mobile devices
✨ **No Horizontal Scroll** - Works flawlessly on any screen size

## How to Run

### Option 1: Using Node.js (Recommended)
```bash
node server.js
```
Then open: http://localhost:8000/

### Option 2: Direct File
Simply open `index.html` in your browser

## Files
- `index.html` - Main HTML structure
- `style.css` - Optima font styling with attractive shadows and full responsive design
- `script.js` - Interactive game logic
- `server.js` - Local development server
- `RESPONSIVE-TEST.md` - Complete responsive testing guide

## Responsive Design
Works perfectly on:
- 📱 Small phones (360px)
- 📱 Standard phones (375px - 414px)
- 📱 Large phones (480px+)
- 📱 Tablets (768px - 1024px)
- 💻 Desktops (1200px+)
- 🔄 Portrait and landscape orientations

## Game Features
- Branching narrative with multiple paths
- Typewriter text animation
- Interactive choices that affect the story
- Personal Valentine's message
- Replay functionality

## Customization
Edit `script.js` to modify the story content, add new chapters, or change the narrative flow.
