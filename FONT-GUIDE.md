# 🎨 Font System Guide

## ✨ Three Professional Font Combinations

### 1. Handwritten + Sans-serif (Default) ✍️
**Perfect for**: Casual, personal, friendly feel

**Fonts Used:**
- **Titles**: Shadows Into Light (playful handwritten)
- **Body**: Caveat (natural handwriting)
- **Buttons**: Montserrat (clean sans-serif)

**Why it works**: 
- Handwritten titles feel personal and romantic
- Caveat body text is readable yet casual
- Montserrat buttons provide modern contrast
- Perfect for the "love letter" vibe

**Best for**: Everyday romantic messages, casual love notes

---

### 2. Script + Serif (Elegant) 🎭
**Perfect for**: Formal, sophisticated, timeless elegance

**Fonts Used:**
- **Titles**: Dancing Script (flowing cursive)
- **Body**: Playfair Display (elegant serif, italic)
- **Buttons**: Playfair Display (consistent elegance)

**Why it works**:
- Dancing Script adds romantic flourish
- Playfair Display is a classic wedding/formal font
- Italic body text adds sophistication
- All elements feel cohesive and refined
- Perfect for "classic romance" aesthetic

**Best for**: Special occasions, formal declarations, timeless love

---

### 3. Bold Display + Light Body (Modern) 🎯
**Perfect for**: Contemporary, clean, impactful design

**Fonts Used:**
- **Titles**: Bebas Neue (bold, condensed, uppercase)
- **Body**: Raleway Light (thin, elegant, readable)
- **Buttons**: Raleway Medium (balanced weight)

**Why it works**:
- Bebas Neue creates strong visual hierarchy
- Raleway Light is airy and modern
- High contrast between bold/light
- Contemporary minimalist aesthetic
- Perfect for "modern love" vibe

**Best for**: Contemporary couples, minimalist aesthetic, bold statements

## 📐 Font Pairing Principles Applied

### ✅ What We Did Right:

**1. Contrast is Key**
- Handwritten + Sans-serif = Personality + Clarity
- Script + Serif = Romance + Readability
- Bold + Light = Impact + Elegance

**2. Hierarchy Maintained**
- Titles always stand out (larger, decorative)
- Body text is readable (appropriate weight)
- Buttons are actionable (clear, distinct)

**3. Limited Font Count**
- Maximum 3 fonts per combination
- Each font has a clear purpose
- No visual confusion

**4. Readability First**
- Body text never sacrifices legibility
- Line heights adjusted per font
- Letter spacing optimized

### ❌ What We Avoided:

**Two Similar Handwritten Fonts**
- Would look messy and unprofessional
- Hard to establish hierarchy
- Visually confusing

**Two Decorative Fonts Together**
- Overwhelming and hard to read
- No clear focal point
- Amateur appearance

**More Than 3 Fonts**
- Creates visual chaos
- Breaks design cohesion
- Looks unprofessional
